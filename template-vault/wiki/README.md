# wiki/ — 知识库层（Claude 维护）

结构化"第二大脑"，由 Claude 按 `CLAUDE.md`（Wiki Schema）维护。

```
wiki/
├── index.md     ← 知识域导航 + ⭐ 新奇观点置顶 + Stats
├── log.md       ← 操作日志（仅追加）
└── (知识域)/    ← 如 AI/、心理学/、投资/
    ├── index.md
    └── (子话题)/
        ├── 来源/   ← 每篇原始资料的摘要页（始终创建）
        ├── 实体/   ← 人/组织/产品（≥2 来源才建）
        ├── 概念/   ← 原理/方法论/术语（≥2 来源才建）
        └── 对比/   ← 跨来源横向综合
```

**给 Claude 的第一句话**：先读 `CLAUDE.md`，再读 `wiki/index.md`，然后开始。
